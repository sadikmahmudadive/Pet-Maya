## Layout Navigation Flow

The following diagram illustrates the primary user navigation flow and how the layout files are interconnected.

```mermaid
graph TD
    Splash[activity_splash_screen] --> Onboarding[activity_onbording_screen1]
    Onboarding --> Login[activity_login]
    Login <--> Register[activity_registration]
    
    Login --> Main[activity_main - Dashboard]
    
    %% Pet Management
    Main --> MyPets[activity_my_pets]
    MyPets --> PetDetails[activity_pet_details]
    PetDetails --> AddEditPet[activity_add_edit_pet]
    PetDetails --> PetHealth[activity_pet_health]
    PetDetails --> PetTracker[activity_pet_tracker]
    PetDetails --> AiScanner[fragment_ai_scanner]
    
    %% Shop Flow
    Main --> Shop[activity_shop]
    Shop --> ProdDetails[activity_product_details]
    ProdDetails --> Cart[activity_cart]
    Cart --> Checkout[activity_checkout]
    
    %% Community Flow
    Main --> Community[activity_community]
    Community --> CreatePost[activity_create_post]
    Community --> Comments[layout_comments_sheet]
    
    %% Services & Booking
    Main --> Services[activity_pet_services]
    Services --> VetDetails[activity_vet_details]
    VetDetails --> Booking[activity_booking]
    
    %% Calendar & Events
    Main --> Calendar[activity_calendar]
    Calendar --> Events[activity_events]
    Events --> AddEvent[dialog_add_event]
    
    %% Account & Notifications
    Main --> Profile[activity_profile]
    Profile --> EditProfile[activity_edit_user_profile]
    Main --> Notifications[activity_notification]
    
    %% Admin Flow
    AdminDash[activity_admin_dashboard] --> Analytics[activity_admin_analytics]
    AdminDash --> Logs[activity_admin_logs]
    AdminDash --> UserList[activity_admin_user_list]
    AdminDash --> Broadcast[activity_admin_broadcast]
```
